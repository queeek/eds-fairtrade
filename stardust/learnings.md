# Learnings — fairtrade.net replica (9 pages, 2026-10-28)

- **Coverage `path` must be the delivered path.** `inventory.mjs` takes the path from the migrated tree (`/en/products/Fairtrade_products`) while deploy delivers the eds-path normalised URL (`/en/products/fairtrade-products`). The assembled sitemap, `assemble.mjs --verify-origin` and the runner's done-check (`pages_not_live`) all read that field, so 4 delivered pages read "not live". Fixed by writing `delivery.deployedUrl`'s pathname into `path`; never re-run inventory.mjs afterwards.
- **`verify.mjs` flags code-only widget links.** `href="/widgets/<path>/<name>.html"` (widget contract) is not a coverage page, so the page reads `broken internal links` although the URL answers 200. Confirm the 200 and the D2 flow, then record the row verified through update-coverage.mjs.
- **Source JSON-LD is content.** The source carried a WebSite JSON-LD on every page; the migrated documents dropped it and only F-optimize noticed (9 P2). A `JSON-LD` metadata row is rendered server-side by the pipeline as `<script type="application/ld+json">` — carry it at render time, not at optimize time.
- **Cluster units should record their blocks.** Coverage blocks stayed `pending` through C-deliver although every page using them was live; H-report surfaced it. Record `--block <id> --status verified --eds-name <name>` at each unit end.
- **unit-geometry's origin cache is keyed by slug, not width.** `stardust/current/measure/<slug>-units.json` written by a 360 gate-all run is read back by the next 1440 run (source tiles 324 px vs build 612 px → "units off" on 6 pages with an unchanged pixel %). Move the cache aside before each width's gate-all run, or run the widths in the order the cache was last written.
- **The header block box must be the pinned root.** chrome-compare resolves the header root to `header > .header`; with that box `position: absolute` and only the inner `.topbar` fixed, scroll-state read "static" at every step (8 errors). Make the block box itself the fixed, hide-on-scroll element (class toggled on it, z-index above the in-page dropdowns, the fixed panels inside keep their order).
